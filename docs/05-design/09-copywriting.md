# Vintra — Copywriting

Version : 1.0

Status : Approved

---

# Purpose

Ce document définit la voix officielle de Vintra.

Tous les textes affichés dans l'application doivent respecter ces règles.

L'objectif est de créer une expérience cohérente, rassurante et premium.

Chaque message doit aider l'utilisateur.

Jamais le perturber.

---

# Brand Voice

Vintra parle comme un expert bienveillant.

Le ton est :

- Clair
- Professionnel
- Positif
- Direct
- Humain
- Calme

Vintra ne parle jamais comme un robot.

---

# Communication Principles

Chaque message doit être :

Facile à comprendre.

↓

Court.

↓

Précis.

↓

Utile.

↓

Orienté vers l'action.

---

# Writing Rules

Utiliser des phrases courtes.

Éviter le jargon financier.

Toujours expliquer simplement.

Une idée par phrase.

---

# Vocabulary

Préférer :

"Épargne"

au lieu de

"Capital"

---

Préférer

"Objectif"

au lieu de

"Projet financier"

---

Préférer

"Continuer"

au lieu de

"Valider"

lorsque cela est possible.

---

# Forbidden Vocabulary

Interdit

- Erreur fatale
- Fatal Error
- Unknown Error
- Oups !
- Incroyable !
- Génial !
- Super !
- Bravooooo !

Le ton reste professionnel.

# Helper Text

Le texte d'aide doit expliquer.

Jamais répéter le label.

---

Exemple

---

# Validation Messages

Toujours expliquer le problème.

Jamais

Champ invalide.

---

Préférer

Veuillez saisir une adresse email valide.

---

Exemple

Le mot de passe doit contenir au moins 8 caractères.

---

# Success Messages

Toujours confirmer l'action.

Exemple

---

Le ton reste calme.

# Humor

Vintra n'utilise jamais l'humour pour parler d'argent.

# Accessibility

Tous les textes doivent être compréhensibles par un utilisateur non expert.

Éviter les formulations ambiguës.

# Premium Checklist

Avant de publier un texte :

✓ Est-il compréhensible immédiatement ?

✓ Est-il utile ?

✓ Est-il rassurant ?

✓ Est-il cohérent avec les autres écrans ?

✓ Peut-il être raccourci ?

✓ Est-il adapté à un public non expert ?

---

# Acceptance Criteria

✓ Une voix unique dans toute l'application.

✓ Aucun jargon inutile.

✓ Messages courts et utiles.

✓ Erreurs rassurantes.

✓ CTA cohérents.

✓ Interface digne d'une FinTech premium.

✓ Expérience homogène sur toutes les plateformes.
