# Vintra — Icons & Illustrations

Version : 1.0

Status : Approved

---

# Purpose

Ce document définit les règles d'utilisation des icônes, illustrations et éléments visuels de Vintra.

Tous les éléments graphiques doivent respecter une identité cohérente afin de renforcer la perception de qualité, de confiance et de modernité.

Une icône n'est jamais utilisée comme décoration.

Elle sert uniquement à améliorer la compréhension.

---

# Philosophy

Les icônes accompagnent l'information.

Elles ne remplacent jamais un texte.

Les illustrations rendent l'expérience plus chaleureuse.

Elles ne doivent jamais détourner l'attention.

Chaque élément graphique doit avoir une utilité.

# Icon Usage

Une icône doit :

- renforcer la compréhension ;
- être immédiatement identifiable ;
- rester discrète.

Une icône ne doit jamais :

- remplacer un titre ;
- être utilisée uniquement pour décorer ;
- être animée sans raison.

# Logo Usage

Le logo Vintra est utilisé :

- écran de connexion ;
- onboarding ;
- splash screen ;
- paramètres ;
- favicon ;
- application mobile.

Le logo n'est jamais utilisé comme élément décoratif.

---

# Illustrations Style

Les illustrations doivent être :

- modernes ;
- épurées ;
- cohérentes avec le Dark Theme.

Éviter :

- les personnages très détaillés ;
- les scènes complexes ;
- les couleurs saturées.

---

# Image Rules

Les photos sont exceptionnelles.

La majorité de l'interface repose sur :

- icônes ;
- illustrations ;
- composants.

Les banques d'images ne sont pas utilisées.

---

# Accessibility

Toutes les icônes décoratives

aria-hidden="true"

Toutes les icônes porteuses de sens

aria-label obligatoire.

Toutes les illustrations possèdent un texte alternatif pertinent.

---

# Forbidden

Interdits

- Mélanger plusieurs librairies d'icônes
- Emojis dans l'interface
- Icônes 3D
- Icônes remplies ("filled")
- Illustrations réalistes
- GIF animés
- Images décoratives sans utilité

---

# Premium Checklist

Avant de valider un écran :

✓ Toutes les icônes proviennent de Lucide.

✓ Les tailles sont cohérentes.

✓ Les couleurs utilisent les Design Tokens.

✓ Les illustrations respectent la charte.

✓ Les icônes améliorent réellement la compréhension.

✓ Aucun élément graphique inutile.

---

# Acceptance Criteria

✓ Une seule librairie d'icônes.

✓ Une identité visuelle homogène.

✓ Illustrations cohérentes.

✓ Accessibilité respectée.

✓ Compatible avec le Design System.

✓ Aspect premium comparable aux meilleures applications FinTech.
