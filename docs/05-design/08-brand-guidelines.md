# Vintra — Brand Guidelines

Version : 1.0

Status : Approved

---

# Purpose

Ce document définit l'identité visuelle officielle de Vintra.

Il constitue la référence unique pour tous les supports de communication, interfaces, applications et futurs produits.

Chaque utilisation de la marque doit respecter les règles définies ici.

---

# Brand Mission

Vintra aide chacun à reprendre le contrôle de son argent grâce à une expérience simple, moderne et intelligente.

Nous ne vendons pas une application.

Nous construisons une relation de confiance avec nos utilisateurs.

---

# Brand Values

Les quatre valeurs fondamentales de Vintra sont :

## Clarity

Tout est simple.

Aucune complexité inutile.

---

## Trust

Chaque détail inspire confiance.

La transparence est une priorité.

---

## Precision

Chaque chiffre est exact.

Chaque élément est réfléchi.

---

## Progress

Vintra accompagne l'utilisateur dans son évolution financière.

Chaque interaction doit donner une sensation d'avancement.

---

# Brand Personality

Vintra est :

- Moderne
- Premium
- Minimaliste
- Accessible
- Intelligent
- Rassurant

Vintra n'est jamais :

- Agressif
- Humoristique
- Tape-à-l'œil
- Infantilisant
- Stressant

---

# Brand Feeling

Lorsqu'un utilisateur ouvre Vintra, il doit ressentir :

"Je maîtrise enfin mes finances."

Jamais :

"Je vais encore devoir remplir des tableaux compliqués."

---

# Logo

Le logo doit être :

- Simple
- Minimaliste
- Lisible à petite taille
- Reconnaissable sans texte

Le logo ne doit jamais dépendre d'un effet graphique.

# Logo Rules

Toujours conserver les proportions originales.

Ne jamais :

- étirer ;
- déformer ;
- faire pivoter ;
- ajouter un contour ;
- ajouter une ombre ;
- changer les couleurs officielles.

---

# Safe Area

Autour du logo, laisser une zone libre équivalente à la hauteur de la lettre "V".

Aucun élément ne doit entrer dans cette zone.

---

# Minimum Size

Logo seul

24 px

---

Logo avec texte

120 px

---

# App Icon

L'icône de l'application doit être immédiatement identifiable.

Caractéristiques :

- Fond sombre
- Symbole unique
- Aucune typographie
- Contraste élevé
- Compatible iOS et Android

Le design doit rester lisible à 16 × 16 px.

---

# Favicon

Version simplifiée du logo.

Taille minimale

16 × 16 px

---

# Iconography

Lucide React

- même style.

---

# Photography

Les photographies sont très limitées.

Vintra privilégie :

- illustrations ;
- icônes ;
- composants.

Les photos de banque d'images sont interdites.

---

# Illustration Style

Illustrations :

- Flat
- Minimalistes
- Peu détaillées
- Palette limitée
- Compatible Dark Theme

---

# Motion Identity

Les animations sont :

- fluides ;
- discrètes ;
- naturelles.

Aucun effet spectaculaire.

Le mouvement doit renforcer la confiance.

---

# Language

Le nom officiel est :

Vintra

Toujours écrit avec :

V majuscule

Le reste en minuscules.

Jamais :

VINTRA

vintra

VinTra

---

# Tagline

Par défaut

Aucune tagline obligatoire.

Si une signature est utilisée :

"Votre avenir financier commence aujourd'hui."

Elle reste secondaire au nom Vintra.

# Brand Consistency Checklist

Avant toute publication :

✓ Logo correct

✓ Couleurs officielles

✓ Typographie officielle

✓ Icônes officielles

✓ Ton cohérent

✓ Aucune surcharge visuelle

✓ Style premium

✓ Respect du Design System

---

# Future Evolution

La marque doit pouvoir évoluer sans perdre son identité.

Les futures fonctionnalités, plateformes ou produits doivent rester immédiatement reconnaissables comme appartenant à l'univers Vintra.

---

# Acceptance Criteria

✓ Une identité visuelle unique.

✓ Une utilisation cohérente du logo.

✓ Une typographie unique.

✓ Une palette maîtrisée.

✓ Une image premium.

✓ Une marque immédiatement identifiable.

✓ Une cohérence sur tous les supports.
